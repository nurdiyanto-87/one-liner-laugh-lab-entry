A tiny Python program that writes one original, deadpan funny line — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`. The joke is a legal-defence twist: the sock was on the floor, unlabelled, and legally indistinguishable from dust, which is the vacuum's whole job.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
